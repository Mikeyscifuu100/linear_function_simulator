# Linear Function Simulator

A Python project that graphs and animates a linear function of the form y = mx + b.

## Features

- Calculates y-values from a slope and intercept
- Plots the calculated points
- Animates the line with a moving point
- Displays the current point's coordinates

## How to run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the simulator:

```bash
python linear_function_simulator.py
```

Change `slope` and `intercept` in the Python file to explore different linear functions.

## Built with

Python, NumPy, and Matplotlib.
